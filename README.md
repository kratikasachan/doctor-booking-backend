**Doctor Appointment Booking (Backend)**

A Flask and SQL REST API for a doctor appointment booking app. Frontend repo: [doctor-appointment-frontend](https://github.com/kratikasachan/doctor-appointment-frontend)

**Working now:** signup, login with JWT token, protected `/me` route. Passwords are stored as hashes.

**Coming next:** doctors list and search, appointment booking and cancel, double-booking check.

**Tech:** Python, Flask, Flask-SQLAlchemy (SQLite), Flask-JWT-Extended

**Run:** create a venv, then run `pip install flask flask-sqlalchemy flask-jwt-extended` and `python app.py`
